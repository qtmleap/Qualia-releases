# Qualia downloads

Signed and notarized macOS DMGs are available in Releases.

Initial prereleases support Apple silicon and macOS 14 or later. A compatible Qualia iPad companion app is required; the companion is not yet available on the App Store.

Verify downloads using the accompanying SHA-256 checksum. Source code and signing material are maintained separately.

[Qualia website](https://qualia-website.lemonandchan.workers.dev)
